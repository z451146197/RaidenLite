# Mission 01 设计简报（供并行工作线参考）

> 目的：把当前已经讨论清楚的第一关方向沉淀成共享参考，减少 1 / 2 / 3 线各自猜设定。
>
> 本文件是“设计基线”，不是要求一次性重写现有实现。若当前代码与本文不一致，先判断是否属于旧实现、占位实现或已完成的新方案，再做最小改动。

## 状态标记

- **LOCKED**：目前已明确同意，除非出现实现问题，不应随意改变。
- **DRAFT**：当前倾向方案，可在试玩后调整。

## 1. 游戏总方向

**LOCKED**

- Cocos Creator 3.8.8，2D 纵向射击，目标微信小游戏。
- 设计分辨率 750×1334。
- 美术方向：写实 / 半写实军武，现实军机原型 + 近未来技术升级，不走卡通、霓虹、塑料感。
- 世界推进：海岸军事基地 → 山地 / 沙漠 / 城市 / 发射设施 → 近地轨道 → 月球 → 深空。
- 玩家视觉机体可以较大，但真实受伤判定为机体中心极小圆形 Hit Point（约 8 px 半径级别）；机翼擦弹不应轻易判死。

---

## 2. 武器与 Build 机制

### 局外决定 Build

**LOCKED**

战场内不再通过捡 `S / L / P` 来强制切换武器。武器选择属于局外 Build 系统。

方向：

- 主武器可包含：Standard / Spread / Homing Laser 等。
- 后续可增加副武器、无人机、导弹、模块、Bomb/Ultimate 等。
- 武器与模块的选择发生在出击前。
- 玩家进入关卡后不应因为随机掉落而被迫改变喜欢的武器。

### 局内成长

**LOCKED**

局内只负责“强度成长与临时爆发”：

- 击杀获得 Energy，自动磁吸或直接结算，不要求玩家横穿弹幕抢拾。
- Energy 满后 `POWER Lv1 → Lv2 → ... → MAX`。
- Power 提升应明显增加弹量、覆盖感和视觉爽感；DPS 增幅可比弹量增长更克制。
- Bomb 作为可靠保命手段：清除敌弹、对敌造成大伤害、给予短暂无敌。
- 特殊 Rare Core / Overdrive 可以作为少量特殊掉落，但不改变 Build，只提供短时爆发。

**DRAFT**

- Bomb 后续可主要通过击杀充能获得；Mission 01 可直接起飞自带 1 发，用来教学。

---

## 3. 敌弹规则

**LOCKED**

- `NORMAL`：橙/黄色轻型弹；可被玩家子弹抵消，双方同时消失。
- `HEAVY`：较大的红色重型弹；不能被玩家子弹抵消，必须走位；Bomb 可清除。
- 后期可有 `BEAM / SPECIAL`，不在 Mission 01 重点范围内。

Mission 01 要通过战斗演示规则，不依赖模态教程：先让玩家自然发现 NORMAL 可消，再用少量红色 HEAVY 明确“必须躲”。

---

## 4. 世界观与命名

### AEGIS

**LOCKED**

核心系统名：`AEGIS`。

它是覆盖无人战机、防空、舰队、轨道防御等系统的全球自动化防御网络。故事不把它简单写成“坏 AI”。其最高逻辑围绕“确保人类文明存续”，但它可能因此剥夺人的控制权。

### 命名方式

**LOCKED**

重要有人驾驶战机直接以飞机名作为无线电呼叫名，不额外使用真实人名或类似传统主角姓名的呼号。

当前：

- 玩家战机：`AURORA`（含义：曙光 / 极光）
- 僚机：`VIPER`
- 僚机：`FALCON`
- 第一关 Boss：`GOLIATH-01`
- 指挥频道：`CONTROL`

无线电示例使用：`CONTROL → AURORA`、`VIPER → AURORA`，不要再使用 `RAIDEN-01` 等名称。

## 5. Mission 01 核心叙事骨架

**LOCKED**

第一关不是从空中直接开打，而是**从海岸基地紧急起飞开始**。

核心顺序：

1. AURORA、VIPER、FALCON 三架仍可人工驾驶的战机在基地滑行、进入跑道并起飞。
2. CONTROL 说明 AEGIS 主控网络异常，AURORA 是少数仍可脱离 AEGIS、由飞行员直接控制的战机之一。
3. 初始任务不是反攻，而是守住基地人员撤离航线。
4. 三机共同作战，VIPER/FALCON 必须真实攻击敌人，不只是背景装饰。
5. 玩家发现来袭目标竟是己方 AEGIS 无人截击机。
6. 教学 NORMAL 可被玩家火力抵消。
7. 教学红色 HEAVY 无法抵消、必须躲避。
8. AEGIS 展示协同战术，集中针对 FALCON。
9. FALCON 先受损、冒烟、失控，随后被 HEAVY 追击并击落；不要“一碰就炸”。
10. VIPER 继续与 AURORA 作战。
11. 玩家看到刚刚起飞的基地正在被自己的防御系统清除。
12. 开场背景中曾经隐约出现的 GOLIATH 从基地防御设施 / 平台升空。
13. VIPER 在 Boss 入场阶段受损，被 CONTROL 命令撤离，但存活。
14. AURORA 单独迎战 GOLIATH。
15. GOLIATH 多阶段爆炸后被击毁。
16. CONTROL 发现 GOLIATH 的命令并非来自海岸 / 区域主控，而来自近地轨道。
17. 关尾给出：`SIGNAL ORIGIN: ORBIT`。

这条骨架是 Mission 01 的剧情与玩法共同主线。

## 6. 起飞演出实现原则

**LOCKED**

第一版不依赖多套逐帧飞机动画。优先使用程序演出：

- 跑道背景加速滚动。
- 尾焰长度 / 强度增加。
- 轻微镜头震动。
- 飞机阴影与机体逐渐拉开、缩小、变淡，制造离地感。
- 三机通过节点跟随 / Tween 完成编队变化。
- 玩家正式获得控制权后再淡入 HUD。

同一张顶视飞机 Sprite 应尽量承担滑跑、起飞、伴飞、撤离等多个状态。

---

## 7. 僚机演出实现原则

**LOCKED**

不为第一版制作大量受损帧，优先程序组合：

- 中弹：局部小爆炸。
- 受损：烟雾、火焰、轻微抖动 / 旋转。
- 坠落：位移、减速、偏转、尾烟。
- 最终击落：Heavy 命中 + 大爆炸 + 隐藏机体 / 碎片。
- VIPER 撤退：受损烟雾 + 飞离屏幕，不死亡。

FALCON 的死亡重点是表现 AEGIS 的协同战术，而不是传统“突然替玩家挡枪”。

---

## 8. GOLIATH 演出原则

**LOCKED**

GOLIATH 需要在开场基地背景中作为不强调的伏笔存在，Boss 前再从背景状态交接到 Gameplay/Boss 状态。

第一版 Boss 动画也以程序组合为主：

- 背景 GOLIATH → 启动 → 升空 → 视觉放大 / 阴影变化 → 进入 Boss 层。
- Boss 死亡不能 HP=0 后立即 `destroy()`。
- 使用多个爆炸挂点分时触发：左右翼 / 武器区 / 尾部 / 中央大爆炸。
- 配合烟、火、震屏、短时闪光完成完整死亡演出。

当前仓库已有 `tools/check-mission01.cjs` 对部分 GOLIATH 交接与死亡生命周期进行结构验证，修改相关逻辑时必须保持验证可解释。

## 9. Mission 01 时间轴（DRAFT，可试玩调整）

当前建议总长度约 2 分 30 秒左右，Boss 约 35–50 秒。具体秒数以试玩节奏为准。

参考阶段：

- 00:00–00:06：基地警报 / 人工控制链确认。
- 00:06–00:14：三机进入跑道、说明 AEGIS 异常与任务目标。
- 00:14–00:24：三机加速起飞。
- 00:24–00:30：HUD 淡入、玩家获得控制权。
- 00:30–00:40：无武装基础无人机，三机共同攻击。
- 00:40–00:52：确认敌机为己方 AEGIS 无人截击机。
- 00:52–01:04：NORMAL 敌弹教学。
- 01:04–01:15：首次 POWER UP，并立即给一波脆弱敌机证明成长。
- 01:15–01:27：精英进入，首次 HEAVY。
- 01:27–01:38：NORMAL + HEAVY 混合，要求第一次真正走位。
- 01:38–01:48：AEGIS 集中锁定 FALCON。
- 01:48–01:57：FALCON 受损。
- 01:57–02:03：FALCON 被 HEAVY 击落。
- 02:03–02:13：短暂降压；看到基地遭清除。
- 02:13–02:21：Boss 前清场，GOLIATH 启动。
- 02:21–02:26：WARNING / GOLIATH 入场。
- 02:26 起：VIPER 受损撤退，AURORA 单机 Boss 战。
- Boss 死亡后：`SIGNAL ORIGIN: ORBIT` → `MISSION COMPLETE`。

若当前实现中的时间轴与上述秒数不同，不要仅为了“对齐文档”机械改秒数；先以 LOCKED 的叙事顺序为准，再结合试玩调整。

## 10. GOLIATH 战斗结构

**DRAFT**

- Phase 1（100%→约65%）：大量可抵消 NORMAL，让玩家感觉火力能够正面开路。
- Phase 2（约65%→30%）：混入少量 HEAVY，开始要求走位。
- Phase 3（约30%→0）：受损烟火 + 更强火力；引导玩家理解 Bomb 的保命价值。

第一关 Boss 的任务不是高难度拦截玩家，而是综合验证：移动、火力开路、识别 HEAVY、Bomb，以及最终演出爽感。

---

## 11. 第一关之后的 Build 解锁

**DRAFT，但方向已认可**

Mission 01 属于紧急起飞，第一关不要求玩家在出击前复杂配装。AURORA 使用标准武装完成教学。

第一关结束后第一次进入 `AURORA HANGAR`，再逐步开放局外 Build，例如：

- Standard Cannon
- Spread
- Homing Laser

第二关开始让玩家体验“出击前决定玩法，局内只成长强度”。

---

## 12. 第一批素材优先级

第一关 V1 优先准备少量高质量静态资产，动画主要靠程序组合。

需要：

- AURORA 顶视机体。
- VIPER / FALCON 顶视机体。
- 基础无人机 / 截击机 / 高速机 / Heavy 精英机。
- GOLIATH 顶视 Boss。
- 玩家弹、橙色 NORMAL、红色 HEAVY。
- 小 / 中 / 大爆炸、烟、火、尾焰、炮口闪光。
- 跑道、海岸基地、海面、云层、机库、防空设施、GOLIATH 停机 / 升降区域。
- 通讯 UI、WARNING、Boss HP、POWER、BOMB、MISSION COMPLETE、ORBIT 信号追踪 UI。

不要因为演出需求就优先制作同一飞机的多角度 / 多帧 AI 重绘。当前优先策略是“静态高质量资产 + 程序演出”。

## 13. 给并行开发线的约束

- 不要重新引入“战斗内捡 S / L 强制换武器”的旧机制。
- 不要把 AURORA 称为 RAIDEN 或给玩家补真实姓名。
- 不要把 VIPER / FALCON 改成只跟随不攻击的纯装饰节点。
- 不要让 FALCON 无铺垫瞬间爆炸；需要受损 → 失控 → 被追击 / 击落过程。
- 不要让 VIPER 在第一关死亡；当前叙事要求其受损撤退并保留后续角色价值。
- 不要让 GOLIATH HP=0 立即销毁；先完成死亡演出。
- 不要把第一关开场改成“已经在空中”；起飞是第一关的一部分。
- 所有大改先检查是否会破坏 `Mission01Timeline`、`Mission01Wingmen`、GOLIATH 视觉交接与现有 CI 检查。

## 一句话版本

> Mission 01 是一次从海岸基地开始的紧急人工起飞：AURORA 与 VIPER/FALCON 并肩出击，逐步发现 AEGIS 正在清除自己的基地；FALCON 被协同战术击落、VIPER 受损撤退，AURORA 独自摧毁 GOLIATH，最后发现命令源来自近地轨道。武器选择属于局外 Build，局内只做 Power / Bomb / Overdrive 等强度成长。
