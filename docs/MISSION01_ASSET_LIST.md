## 程序演出代替额外美术帧

以下表现 **v1 不要求额外飞机帧**：

- AURORA 滑跑加速：背景滚动加速 + 尾焰增强 + 轻震
- AURORA 离地：阴影缩小、变淡、与机体拉开
- 三机编队：节点跟随 / Tween
- 僚机转向攻击：位置 + 轻微旋转
- FALCON 受损：局部爆炸 + 烟 + 火 + 抖动
- FALCON 坠落：减速 + 偏转 + 下移 + 尾烟
- VIPER 撤退：中弹 + 冒烟 + 向左下飞出屏幕
- GOLIATH 升空：背景层 → 放大 / 阴影变化 → Boss 层
- GOLIATH 死亡：多个爆炸挂点按时间触发 + 烟火 + 震屏

## GOLIATH 死亡挂点建议

至少准备 5 个可重复使用的逻辑挂点：左翼、右翼武器区、尾部、机体内部 / 中段、中央核心。挂点不要求单独绘制资产，可以共享同一套爆炸与烟火素材，通过位置、缩放、旋转和时间差制造完整死亡演出。

## 不要在 v1 先做的内容

- AURORA 左 / 中 / 右三套独立倾斜 Sprite
- 僚机完整逐帧受损动画
- 起落架完整收放帧
- GOLIATH 武器舱复杂逐帧开合
- 为每种敌机单独制作完全不同的爆炸动画

这些内容只有在基础玩法、第一关节奏和现有素材稳定后再考虑升级。

## 美术方向约束

第一关统一走写实 / 半写实军武方向：现实军机结构逻辑 + 近未来技术改造。避免卡通、霓虹街机感、塑料亮色。AURORA 以深蓝灰 / 金属为主，青色能量只做局部强调；AEGIS 敌机可使用红 / 橙识别与威胁标记，但仍保持真实军用载具结构。

## 场景连续性要求

开场基地必须在后续“基地遭清除”和 GOLIATH 升空时保持空间上的连续性。GOLIATH 停机区需要在开场就能被看到，但只作为伏笔；Boss 前再通过平台开启、阴影、升空与 WARNING 把它提升为主角。
